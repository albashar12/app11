# app11
A secure, client-side web application that uses the Telegram Bot API as a free and unlimited cloud storage backend. Files are masked upon upload to hide them within the native Telegram app, ensuring privacy.

## Features
- Minimalist Dark-Themed Glassmorphism UI
- Single-page application architecture
- "File Masking" for privacy inside Telegram
- Built with HTML, CSS, and vanilla JavaScript

## Setup
To use this, simply host the files using GitHub Pages and enter your Telegram Bot Token and Chat ID on the setup screen.
